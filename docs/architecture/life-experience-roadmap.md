2026-11-03，设计基线 8870079。面向 Android 日常随手用和 Web 集中整理。前两轮已定义[核心页面](daily-wellness-experience.md)和[功能入口](feature-discovery.md)，本轮补齐首次使用、数据可信度、跨域日程、离线恢复与宽屏交互。[打开可操作的一周样稿](prototypes/wellness-week.html)。

## 一天里要做的事

| 时刻 | 首屏上先看到什么 | 操作后回到哪里 |
| --- | --- | --- |
| 第一次打开 | 日期、搜索与全部功能；第一张空卡给“记第一餐”“记录体重”，设备接入另有入口 | 保存成功后原卡出现刚记录的内容；再次进入直接显示已有记录 |
| 早上看身体 | 上次称重的值、单位、日期；昨晚主睡眠注明醒来日期 | 点值进入同次测量，返回保留选中的指标和时间范围 |
| 午饭后记餐 | 选中餐别，最近吃过的食物在搜索框下；一行一个食物，数量与单位并排 | 离线保存也能在同一天看到该餐的本机状态；收到回执后在原位置更新 |
| 傍晚运动 | 散步用“补记运动”；训练草稿显示动作名、当前组与继续按钮 | 中断回到原动作，结束后打开本次已完成组摘要 |
| 周末整理 | 可选日期的周视图，明确几天有称重、几天记过餐 | 选某日展开身体、餐次、运动，编辑后留在该日；宽屏将日期栏留在左侧 |

## 重点领域的下一层设计

### 健康与恢复

- **趋势和测量分开看。** 趋势默认最近一个有覆盖的常用范围，显示实际起止日；单点只画测量点，缺失段留空。点某日可查看当日多次测量及来源，明确周视图采用的那一次。跨设备同日体重、主睡眠按已有复盘口径选择。用户不需要从修订号判断今天称重有没有成功。
- **睡眠跨午夜。** 标题为“周二醒来”，正文显示“周一入睡 → 周二醒来”；午睡和其他会话另列，只有可用分期才画分段。把来源未同步、请求失败和已读完但无睡眠分成三种状态。运动后的主观感受只采用用户填写的内容。
- **一周回看。** 默认 7 天，30/90 天沿用现有查询。在体重、睡眠、训练、摄入各自的标题旁说明覆盖天数。比较前一期时显示两期各自的分母；覆盖不足先展示日期明细。只有具备两域权限时显示联合复盘，单域查看仍可用。[联合复盘口径](wellness-review.md)

### 饮食与食材

- **经常点同样午餐。** “最近一餐”按餐别优先列候选，显示日期和食物摘要，点选后原地进入可编辑草稿。个人修改后的份量优先显示。可用单位来自该食物已知换算，半碗和 100 克之间缺基准就让营养留空。
- **只有照片也能整理。** 给已记录餐次补照片时先显示已选缩略图，上传失败只重试附件。只有照片时先保留原件和日期，用户可返回补充摄入条目；有明确餐次回执才更新已吃餐数。识别、估算与用户确认按来源标示。
- **从买菜到吃饭。** 食谱内显示“加入餐单”，按餐单生成购物清单，采购时回到原清单。库存消耗单独记录。购物、入库和吃过分别显示发生日期；订单与饮食只通过已有真实关联互相打开。到期顺序与日期未知分组，临期天数沿用业务规则。

### 运动与训练

- **补记和实时训练各有版式。** 补走路只需选类型、日期，可填时长；有距离和可比单位再显示配速。力量训练页只放当前动作、上次同口径表现和本组输入；动作说明可展开。耐力活动按时间与距离展示，力量活动按实际组与次数展示。
- **中断和纠错。** 从锁屏回来按绝对截止时刻恢复休息。退出草稿后用同一个“继续训练”入口。撤销已完成组立即恢复可编辑，结束前列出实际完成的动作与组数；已保存的活动从详情进入可支持的更正路径，设备来源只读。
- **回看进展。** 训练记录行优先显示“划船 · 3 组”或“步行 · 25 分钟”；点开才看每只哑铃重量、单侧次数和组间明细。只对同动作、同单位的已完成组显示上次参照；没有可比历史就直接开始。

## 其余领域怎样用得顺

| 区域 | 页面和动作 | 失败或空态 |
| --- | --- | --- |
| 首次使用、生活首页 | 空账号保留搜索、全部功能与首个记录动作；已有账号保留原卡片排序、尺寸与隐藏状态。编辑首页提供实时紧凑预览和无障碍上移下移。 | 某卡获取失败就地重试，其他卡继续可用；设备权限在使用相关功能时说明用途。 |
| 记录与更正 | 默认事件视图；同一称重的一组指标可展开；按日查看的日期固定在页头。详情给“更正”和“查看来源”，确认后返回原列表位置。 | 已有更新时并列显示自己的待保存值与最新值，可保留输入重试；设备原始记录显示来源。 |
| 消费、次卡、物品 | 次卡首页显示剩余次数和最近一次使用。账单核对页并排显示来源行、原交易及差异；手机按相同字段上下对齐。保修从物品进入凭证和到期日。 | 金额相同但币种不同分别呈现；只有金额或名称相似时列候选。已过退货期、未知保修期各用准确文案。 |
| 计划、回顾、提醒 | 今日行程分“此前到期、今天、接下来”；对象行用“打开事项”，提醒行单独“稍后提醒”。某个周期账单进入本期明细。回顾从周或具体日回溯依据。 | 已读、已处理和实际付款各自保留。通知目标已归档时保留原通知摘要与日期；等待目标身份的提醒先进入收件箱。 |
| 旅行与地图 | 行程首屏显示当日住宿及下一段交通。地图选择一个地点同步定位列表，返回恢复日期与地图位置；离线上一次导出的行程显示生成日期和旅程范围。 | 只有部分行程可离线时列出可用日期；未保存地图或原件，分别说明可读范围；无坐标继续可看文字行程。 |
| 资料、票券、附件 | 列表优先展示标题、类型和命中片段，票券加有效时间；正文未处理时可打开原件。移动端原件返回原搜索，桌面左侧筛选列表与右侧阅读联动。 | 识别失败只在正文区域重试。无法定位命中页时显示来源摘要；原件无法获取与无搜索命中采用不同提示。 |
| 自动采集与设备 | 应用使用、录音、地点各显示“最近采到什么、何时采到、从哪来”；进行中状态条能返回当前任务。设置按设备来源、采集开关、同步队列分组。 | 拒绝权限仍能手动记录；后台有时间缺口就展示缺口。停止后保留已收材料，资料副本与采集原件分开。 |
| 助手与手动操作 | 助手回答可从引用跳到所选日期、记录或原件。执行中的任务显示当前状态，回来接着看同一任务。快速记录独立于对话。 | 尚未接入的动作不显示可执行按钮；历史任务可恢复时先读已有进度，避免刷新后重复发起。 |

## 四种容易混淆的页面怎样排

**① 今天要做什么。** 首页以近况和下一步为主。进行中的训练卡显示“上肢训练 · 2/4 个动作　继续”，同一张卡结束后换为“已完成 4 组　看记录”。若首页同时有录音与训练，录音停止入口留在底部状态条，训练继续入口留在原卡；用户的排序照旧。周摘要只占一行“回看过去 7 天”，点开才进入完整周视图。

**② 今天发生过什么。** 单日页首行固定日期，下面依次列称重、睡眠、饮食、运动。早晨检查优先读最新时间；补记优先看餐别。单日有多次称重时用“07:12　68.4 kg”“19:06　68.9 kg”两条可点的行。日期切换只换内容，星期、相对日期和数据覆盖随之更新。用户从周视图进入时沿用所选日，从通知进入时沿用通知对象日。

**③ 买了什么、吃了多少。** 订单详情突出实付、商家和商品，餐次详情突出食物和摄入量。显式关联后双方都有“查看关联午餐／查看付款”一行。餐次更正面板中直接改“半份 → 一份”，已知营养随可用基准重算；同页对照原订单购买数量，只读。取消编辑不打断当前阅读位置。

**④ 有东西需要我处理。** 收件箱的行显示事项、到期或产生时间、具体动作，例如“月卡到期 · 周五　查看次卡”。设备掉线、附件失败等可恢复状态先在相应页面就地处理；用户点“看详情”才看到设备或附件信息。相同来源多次通知只在有稳定身份时折叠。关闭系统提醒后仍可从收件箱回到事项。

## 视觉与状态规范

窄屏单栏阅读，概览控制在日期、一个主值、一个主动作；多条记录用有分隔的列表。浅色保留暖白，暗色用纯黑外底，健康绿、餐食珊瑚和睡眠紫只辅助识别。时间与单位紧靠数值，图表同时提供按日读数。触摸区至少 48 dp，重要按钮放在键盘上方；200% 字体时将并列输入变为上下排列。宽屏有足够空间就并排放列表和详情，缩小时保留选中对象。Web 弹层支持键盘进入、Tab 循环、Esc 与关闭后焦点归位；有草稿时沿用当前离开处理。

| 状态 | 用户看见 | 恢复路径 |
| --- | --- | --- |
| 正在取新日期或新指标 | 标题和占位使用新范围；可用的旧值带原日期 | 只有匹配本次请求的响应能更新该区域 |
| 已有可读缓存 | “上次更新 09:15”，局部显示刷新状态 | 可继续读；手动刷新失败保留缓存 |
| 已读完、确实为空 | “当天没有已记录午餐”及记餐入口 | 继承选中日期与餐别 |
| 缺少营养或时长 | “3 项中 2 项有热量”，未知显示横线；显式零显示 0 | 有权编辑时从具体条目补记 |
| 草稿、待同步、已同步 | 草稿可续填；本机保存后显示队列状态；回执到达后更新同一行 | 重试复用原命令身份；已保存对象不重复创建 |
| 有冲突或仅部分完成 | 标明哪条已保存、哪条需处理，并保留输入 | 重试失败部分，后台重新核对修订及账号；无需重填整餐 |

## 分批验收

| 批次 | 可独立交付的变化 | 发布前要演练的场景 |
| --- | --- | --- |
| 1 · 先看对 | 历史餐次完整性、资料分页空态、Web 指标竞态、来源标签、对象选择防串页 | 目标只在第二页、快速切两项、旧请求延迟失败、数据缺失与真零、账号中途切换；新旧页面显示同一次事实 |
| 2 · 日常少点几次 | 入口目录、身体指标查看与管理分离、简洁记餐、继续训练、进行中采集直达 | 隐藏首页领域卡后仍找得到；三食物记餐无需展开营养；戴手套或单手是待观察条件，用实机测键盘避让与当前组操作 |
