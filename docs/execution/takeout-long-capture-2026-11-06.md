# 外卖长订单采集与付款材料归组

Android 2.1.43（65）支持在开启的外卖应用中摇一摇，回到订单顶部后滚动截图并本地识别；也可直接把系统长截图分享给 Life。商品与选项、数量、行实付、打包费、配送费、优惠、订单编号及下单时间进入采集观察，原图保留在资料来源。

同一外卖编号重复采集只补充来源。外卖观察不自动新增支出；完整且金额核对一致的观察可以只读归组到唯一匹配的既有付款。付款成功页与后补账单的归组一并发布，原始材料不删除，正式消费不重复。

## 验证

- `pnpm check` 与完整隔离回归 527 项通过；其后新增 OCR 标点、配送费错字、取消订单的内核测试通过。
- Android 应用单测、Debug lint 与发布 lint 验证；实际签名和部署回执位于工作区运维资料。
- 在隔离 Android 模拟器上，使用两张用户原图验证本地长图 OCR；以重叠片段验证实际文字锚点和拼接算法。第一张 8 行、商品及费用总计 19.98 元、总价与优惠均核对一致。第二张 5 行、订单实付 23.26 元及费用正确，其中零元选项的单独金额未稳定识别，保留空值与核对提示，不反推金额。
- 原图、OCR 原文及其个人字段未进入 Git；仓库测试只使用合成商家、商品、订单号和时间。

## 边界

- 真实外卖应用的手势与折叠控件尚未在用户手机验收；系统长截图分享路径已用原图离线验证。未安装或覆盖用户手机应用。
- 美团已接入采集入口，缺少真实样本验证其各版本布局；不把入口可用等同于字段识别完整。
- 收货信息、广告推荐不进入商品或付款结构化字段。外卖履约状态与下单时间不替代付款事实，不自动记录实际用餐或营养。
- 此功能不做业务数据迁移，不批量重导订单；服务端迁移数保持 54。

实现说明见[长订单采集架构](../architecture/flash-order-capture.md)，使用见[Android 采集指南](../guides/android-capture-suite.md#外卖长订单)。
