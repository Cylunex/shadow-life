# 2026-10-15：网页资料与助手恢复交付

实施基线为干净的 `a5c2126`。本批完成方案 P1、P2、P3，范围为 Web 与共享后端。
[使用说明](../guides/web-snapshots-and-assistant-recovery.md)和
[架构与限制](../architecture/web-snapshots-and-run-recovery.md)记录最终行为。

## 实际交付

- Library 接受 UTF-8 HTML / SingleFile，沿用固定原件、Executor、任务唯一键、租约与 attempt。
  本地 Worker 有输入、DOM、正文、内存和真正可终止的时间限制，不执行脚本或加载资源。
- 原件、纯文本派生、处理器版本、普通正文修订、片段与哈希证明可追溯。处理中用户更正优先，历史片段
  不混入当前搜索。中文完整词、英文词和标题检索以及既有 Agent 来源读取可用。
- 上传流程为捕获与排队持久保存稳定命令 ID，覆盖服务端已提交而回包丢失、以及命令日志清理后的阶段恢复。
  明确另存仍创建新资料，相同网址和原件哈希不覆盖旧资料。
- 助手状态投影与网络观察从 `main.tsx` 分离。按 Run 连续序号去重、检测缺口、分页排空、退避补读，
  刷新从服务端发现原 Run 并重建答案、来源和回执；恢复不重复发送消息或执行写入。
- Host 活动事件不复制参数，“已保存”仍只能由 Executor 回执产生。停止请求与真实终态分开呈现，
  停止发生在提交后、Host 发布前时，原有回执恢复逻辑仍能补发一次真实回执。
- 公共 Host / 分页合同归入 contracts，Adapter 保留原导出，Runtime / MCP 接口和外部 Agent 检查点保持独立。
  新分页字段是增量扩展，未携带 limit 的既有客户端可读完当前 Host 上限内的整个运行。

没有数据库迁移或新队列；没有原生页面扩建。

## 后续验收边界

协议、领域状态和本地浏览器流程已验收。受控 Runtime 结果不代表真实模型任务成功率，未运行付费模型、
刷新 Gateway、发送外部消息或操作生产。服务进程退出后遵循现有租约中断策略，未承诺模型自动续跑。

复杂站点、CSS 隐藏、多个文章区块和真实 SingleFile 大文件仍需要更多用户样本；首批采用保守结构提取，
不声明 Readability 等价性或全面的登录/付费墙识别能力。生产性能、真实模型与 Android 物理设备行为
不在本地回归的证明范围内。没有部署、生产配置/数据变更或 APK 构建。

同条资料多原件历史、网页自动抓取、PDF 页级解析、离线正文缓存、语义召回和标准 AG-UI 适配保持后续候选。
