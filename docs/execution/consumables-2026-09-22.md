# 消耗品与消费展示修正

购买可在同一事务建立待启用消耗品；支持启用、实际使用、误记撤销、结束批次以及独立的日用量
估算。保留已有燕麦饮食匹配与折叠订单补录入口。Web 购买详情可直接追踪商品，计划页提供使用
管理；Hermes 工作流说明购买排除项、历史不确定性和估算边界。

账目列表、时间线和搜索显示具体购买名称，读取购买信息仍受权限限制。网页导航切换回到顶部，
异步布局不再锚定页尾；Android 消费/健康标签切换重置列表位置，详情以记录标识隔离组合状态。
Android 消耗品展示适配待启用与估算字段。

验证：隔离 PostgreSQL 全量回归 269/269 通过，新增 MCP 路径单独验证；合同生成、TypeScript、
依赖边界、Web 生产构建和 Android :app:compileDebugKotlin 离线编译通过。浏览器实测 80 袋咖啡
由待启用进入使用中，记 1 袋后余额为 79；从页面底部切换分区后 scrollY=0。未构建签名 APK。

部署版本、配置备份、用户历史关联及 Hermes 更新回执仅存本地 operations，不进入代码仓库。
