# Life 页面改版交付

2026-11-20。设计覆盖 Android 日常使用和 Web 的宽屏整理流程。[页面改版设计](../architecture/mobile-page-design-2026-11-20.md)

## 实现

- Android 首页把重点服务放在首行，保留展开入口和卡片偏好。模块根页可直接回到生活，首屏底部可打开快记。记录先显示时间线，间隔事项与生活复盘可以单独打开。
- 健康先显示当天活动、最近主睡眠和最近体重。称重入口打开准确的测量事件。睡眠按设备提供的分期时长展示构成，有实际起止时间才绘制多晚作息。健康档案分别浏览报告和不适发作，已知报告页码和原件入口随结果显示。
- 饮食把日期、已知营养和餐次放在一起。记餐可多选常吃或搜索到的门店菜品。复用整餐保留原份量、营养、食用比例与已有证据。Android 的餐次编辑入口可逐项修正、补录或移除食物，Web 支持在详情更正实吃比例并刷新日合计。
- 消费按月份和币种展示已加载流水小计。账单候选采用紧凑列表，可核对原始行与已有流水、择选退款原交易，按正式回执刷新。规划汇集预算、订阅、次卡与消耗品。原订单统计、售后与常购单价都有独立入口。
- 购买行可转入持有物品、待启用的消耗品或食材批次。重复转入会返回已关联记录。库存批次保留回到购买来源的入口。一个购买行对应一个由此快捷入口建立的库存批次。
- 食谱按原份数换算有明确数量和单位的食材，提供逐步烹饪视图。出行的当天地图可收起，站点可定位。物品可按房间浏览近期退货和保修事项。采集按订单、时间线和设置组织。训练休息条在执行页底部，餐图与金额原件支持放大。

## 数据行为

- 页面区分未记录、部分记录、估算值和已加载明细。营养覆盖按具体食物统计，日完整性读取单独的日记声明。
- 手机写入沿用加密同步队列。餐次日期更正和食物更正保留各自的修订与回执。跨端操作使用共享的 Executor。
- 新增迁移 `0070_food_stock_purchase_source.sql` 记录库存批次的购买来源，已有批次的来源保持缺省。后台核对购买主体、状态与行身份。

## 验证环境

- 使用本机隔离 PostgreSQL 和合成资料。浏览器场景包含健康详情、按日记餐、份量更正、购买与饮食关联、逐笔对账、明细搜索和窄屏布局。
- 隔离 PostgreSQL 全量回归 579 项通过，包含购买来源归属及重复转入的并发验证。
- Android Kotlin 编译通过，应用 160 项及数据模块 3 项单测通过，Debug Lint 0 个错误。Compose 导航回归覆盖 320 dp 布局。蓝牙接入、采集权限、读屏和离线重连的真机体验仍需在实体手机复核。
