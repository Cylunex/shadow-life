# 首页、消费与体脂秤交互修复

2026-11-05。针对 Android 实际页面与消费读取故障完成代码修复。

- 消费列表将过长商品组合／备注限制为展示摘要，避免单条标题超过合同长度使整页失败；数据库原文、详情及完整文本搜索保留，分页不变。
- 消费概览优先显示已加载收支与最近三条明细；消费分析按需展开，空预算与消耗品摘要不占首屏，相关功能仍从管理入口进入。作废记录不参与概览金额，币种独立，明确标注已加载范围。
- 采集订单首先展示材料、金额和入账状态，规则设置默认折叠；未入账展示当前规则未开启、缺少明确实付或来源冲突等可观察信息，不自动修改规则或补写历史账目。订单号与附加字段可以展开查看。
- 首页生活概览改为当天餐次与已入账净支出入口；体脂秤缩成读数、状态和操作，保留已有自定义卡片顺序。新布局／重置布局优先显示当天信息。
- 体脂秤增加「取消接收」，停止扫描与尚未保存的合并等待，清除超时任务；已开始保存的稳定读数完成入队后再关闭服务，已保存数据继续同步。取消后的旧广播和旧会话延迟停止不能影响新接收。
- 最近信息默认两条，可展开至五条，单行标题截断；返回或数据变化触发的自动读取至少间隔一分钟，手动刷新可立即读取。本机同步状态不等待网络节流。读取状态由首页导航级 ViewModel 保存，滚动移出卡片不会重新清空结果或取消并重启请求。
