# 日常体验与功能入口实施 · 2026-11-03

本轮承接[日常健康](../architecture/daily-wellness-experience.md)、[入口设计](../architecture/feature-discovery.md)和[全产品设计](../architecture/life-experience-roadmap.md)。沿用现有 API、权限与加密命令队列，公开合同及数据库结构保持兼容。

## 已实现

- Android 首页放大镜进入功能查找。目录分别提供睡眠、身体、训练与动作库、复盘、食谱、购物清单、库存、次卡、账单核对、订阅、物品、生活回顾和采集各分区。非空关键词同时展示真实记录，也可继续查看全部匹配，返回目录保留关键词。
- Android 餐次按选中日期调用有范围的搜索，读完当天游标后逐餐获取有效条目，按实际食用比例汇总已知营养。读完前和失败时不会展示空日结论。日期可直接选择，餐次排列提前到营养卡之前。复制最近一餐只带名称、份量与单位，使用独立草稿路径，照片、营养和付款关联留在来源餐。
- 食谱与食材改为餐单、购物清单、库存及食谱四个分区，可从目录直接进入。食谱分区可搜索已保存食谱及展开做法，保留既有导入与保存能力。记餐的可选营养默认收起，其他领域的附加信息使用对应文案；补记运动提供步行、跑步与骑行选项。
- Android 接入真实联合复盘查询，提供 7/30/90 天范围、日期选择、分域覆盖、逐日读数、前期营养比较和统计口径。Web 增加日期列表与当天详情，窄屏横向选日，宽屏并排查看。
- 两端训练执行显示当前动作并可切换，按同动作身份、单位及器械查询上次有效事实，参照不写入本次组。Android 执行使用全屏任务面板，键盘上方保留完成当前组；离开仍保留草稿，首页提示继续。Web 保留当前动作导航和固定完成入口。
- Android 身体卡能直接打开最近称重。身体指标选择与显示管理分开，趋势按实际日期定位并断开缺失日。健康与消费分区在当前页面生命周期内分别保留滚动状态。
- Android 录音、地点状态条直接进入对应分区；结束录音显示正在保存。资料分页未读完时不显示完整空态。生活回顾展开后靠近页首，目录可直接打开回顾列表。
- Web 功能目录按实际能力过滤，支持理发卡、保修等生活词。跨分区导航进入浏览器历史，支持后退。弹层补充输入聚焦、Tab 循环、Esc 和关闭后焦点恢复；窄屏页头分行避免重叠。
- Web 趋势按请求代次隔离旧成功与失败，仪表盘刷新也不能覆盖更新的指标选择。对象选择器隔离关键词、账号请求范围及旧翻页结果，保留所选对象摘要。健康来源文案仅描述存在的来源，算法信息收入详情。
