# 2026-10-14 个人 Agent 数据底座交付

基线 `e2d19c1`。按个人 Agent 数据底座与应用的目标完成四步源码实现；设计与具体边界见 [架构方案](../architecture/personal-agent-foundation.md)。

- 新增六个写能力与七个读取能力，共同接入 HTTP、CLI、MCP、内置助手和 Executor。Migration 0047 保存意图、检查点、经验、订阅、修订历史、独立消费游标和提交顺序变化日志。
- 规划上下文包含有效意图、实际记录、项目行动、餐单库存、相关资源、设备来源状态、未完成任务与有依据经验；使用一致快照，区分事实、计划、来源与推导，保留未知和截断提示。
- 来源接入沿用既有领域和原件路径，增加统一对象、别名、正文及两跳关系读取；场景、归属和依据权限在所有入口重新校验。
- Web 计划 → 目标与助手可编辑目标偏好、检查点，查看经验、规划材料与依据，导出当前类别并恢复新副本。Android 计划提供同类核心意图和任务入口，写入复用账号隔离离线队列，收到真实回执后刷新。
- 外部客户端使用真实操作回执、检查点和短期租约恢复任务；订阅变化逐消费者确认，不自动通知。经验关联环境、版本、限制和可核对依据，更正或权限变化后不继续返回失效经验。
