# 首页采集展示与最近信息

2026-11-05。Android 代码交付；未部署服务、构建 APK 或操作生产数据。

## 体验

- 原「采集与回顾」独立写在可配置卡片前面，导致始终占据首页顶部。现在纳入「编辑首页」，默认放在末尾，可移动或隐藏。
- 新增「最近信息」，默认跟在「生活概览」之后，也可移动或隐藏。已有布局只在首次升级时引入两张卡片，保留原卡片相对顺序，后续尊重隐藏设置。
- 摇一摇收录后，首页先显示本机待同步状态和可查看的采集文字；上传、结果核对、失败和受阻分别标识，并可进入现有设置页查看同步队列。
- 已收录材料打开采集原文；单项采集的成功回执同时包含付款和消费记录时，回读消费详情后显示金额和入账状态，点击直达消费详情。原材料到期清理不影响仍然存在的消费详情入口。
- 最近信息合并最近生活记录，最多展示五项，同一消费详情去重并保留采集处理结果。提供「采集订单与记账结果」「全部记录」入口，摇一摇 Toast 明确指向首页最近信息。

## 数据与边界

- 复用账号和主体隔离的加密队列、既有读取 API 和详情路由；不新增数据库字段、公开合同或业务写入路径。
- 本机监听最近 100 条活动采集命令，排除后台应用使用区间后最多解析八项，与现有时间线最近一页合并。此卡用于近期入口，完整历史仍在采集订单和全部记录。
- 先核对回执协议、命令、能力及成功状态；批量回执缺少逐项关联，不按资源顺序、金额或商户猜测对应账目，转到采集订单核对。
- 已完成命令不直接展示留存在队列中的原文，使用仓库读取结果；读取失败提供刷新，沿用现有离线读取策略。只有材料收录不等于入账，也不会推断饮食事实。
- 返回首页自动刷新，页面暂停时取消读取；来源与时间线并行读取，单项失败不阻断其他结果。
