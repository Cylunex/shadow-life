# Android 采集完整功能交付

日期：2026-10-30。Android 版本 2.1.30（52），继续使用现有 Life 账号、API、Executor 和加密同步队列。

- 补齐本机 Whisper 分段转写与中英文 Tesseract OCR 适配器；支持既有 HTTP 处理器，API 与 Worker 共享配置状态。后台音频、OCR、回顾与维护独立限量轮询，不调用付费模型。
- 活动行为、生活领域、Life 项目关联、应用默认分类与人工更正修订；目标复用已有个人意图。日／周／月统计以区间并集计算，展示采集覆盖限制，并联读有权限的领域事实。
- 首页采集概览、记录页直接入口、采集／应用／分析页签、来源详情与全来源分页检索；共同时间线、搜索和 Agent 来源引用接入采集材料。
- 本机记录、上传、模型处理独立控制；每日处理预算、积压与存储状态、近期删除、保护标记及用户主动启用的原件保留策略。关闭处理使旧尝试失效，来源变更使派生回顾失效，删除同步清除旧回顾引用内容。
- ZIP 选择性原件导出与分批恢复：账号加密暂存、完整性校验、可重试身份映射；不恢复权限或自动记账。原件到期只清理没有其他资料引用的音频。
- 迁移 0053、共享生成合同、Android DTO 与同一 API 能力发现；原有应用使用、屏幕文字、截图磁贴、录音、停留地点、订单关联和分层回顾继续使用。

验证：完整隔离回归 479 项通过，Android app 72 项与 devices 12 项单测、Kotlin 编译、发布 lint 通过。补充覆盖分类／项目／目标权限、区间并集、人工修订、来源引用失效、恢复重试、原件清理、暂停与处理预算。修复旧回归的数据库连接关闭时序及并发测试屏障，避免随机 teardown 失败。

处理器另以合成中文语音和合成订单图片实测，模型与语言包只用于离线本机推理；OCR 仍可能误认个别文字，识别内容作为来源材料。真实用户设备的 24 小时采集、锁屏、来电、进程终止、厂商权限与电量实测未完成，不能据单元测试声称已通过。
