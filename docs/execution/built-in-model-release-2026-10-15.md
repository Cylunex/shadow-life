# 内置模型接入与发布验收

用户已明确授权复用现有模型、真实模型验收、代码推送、服务部署与签名 APK 打包。

- 新增内置 Chat Completions Runtime，保留外部 NDJSON Runtime 的配置优先级。
- 动态发现工具并与 Host 权限取交集，实际写入仍由同一个 Executor 执行。
- 校验工具回传、重复 ID、模型响应与运行预算；供应方错误脱敏，不自动重试。
- 真实模型测试扩展为历史查询、无证据问题和实际保存回执，使用临时数据库且有结果断言。
- Android 版本递增至 2.1.23（45）。

验收包含合同、架构边界、类型检查、完整离线测试、18 类 Agent 离线不变量、真实模型样本，
以及桌面和窄屏 HTML 资料、断网恢复与停止流程。真实部署资料、模型配置、数据库备份、
签名 APK 和公网检查证据只存仓库外的 operations。物理设备安装另行验收。

最终代码验收：`pnpm check` 通过；完整离线 362/362，Agent 离线 19/19，foundation 11/11，
适配器单元测试 14/14；真实模型 3/3（11 次供应方请求）；浏览器 7 类流程通过；
Android 单元测试 50/50。真实模型最终使用指定能力，且查询样本没有写入副作用。
