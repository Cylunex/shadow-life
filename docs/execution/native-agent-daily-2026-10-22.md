### Android

- 食品库存优先展示，录入默认收起；按服务端状态筛选 7 天内到期、已过期、日期未知和已用完。
  展示判断日期、时区、已加载数量与截断。校正保留原备注、批次和预期修订，界面重建保留编辑身份。
- 物品支持名称和位置路径组合搜索、持有/退货/保修筛选；详情显示同一份期限判断。
  不持有、没有日期、未加载状态彼此区分；超过读取范围不声称完整。
- 预算/周期等规划支持按月切换并回到本月；读取请求沿用 ViewModel 的请求代次与取消机制，
  账号切换重置月份。正在提交时不切换月份；预算编辑固定原分类，避免变成另一项预算。
- 预算明确显示支出原额，退款不冲减此口径；展示预算和周期读取上限。周期事项区分待处理与全部期次，
  展示原定/调整日期及未知金额；已处理或忽略不生成消费记录。
- 离线行程保存范围外日期、跨夜住宿、结束/到达时间、确认号、座位和备注，清单分别显示待准备/已备好/无需准备。
  退房日不显示当晚入住，取消/退款预订不计入当晚住宿；预订状态不证明实际入住。
  渲染器使用已有 Kotlin JSON 库，可以在普通 JVM 测试，输出纯静态、转义后的 HTML。

### Agent

- 共享目录补齐物品售后、预算、订阅续费等业务词与口径。中文任务匹配多条具体别名时提高排名；
  英文别名按完整词匹配并支持词序变化；NFKC 归一化保留全角能力名查找。
- 查看类表达优先排序对应的读取工具；明确写入不会因含有“库存”等词而变成读取。
  这是确定性工具排序，不是对用户写入意图的执行授权；权限与场景仍在排序前过滤。
- full/compact MCP 对已识别能力的参数错误附带 `recovery.schema_lookup`，直接指出如何通过
  `agent.discover` 读取合同。没有提交写命令，也不自动换命令键；未知结果和冲突恢复规则保持原义。
- [接入与调用示例](../agents/integration.md)。
