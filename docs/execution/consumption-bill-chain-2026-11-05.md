# 消费、账单与饮食关联优化

2026-11-05。代码交付；未部署服务、打包 APK 或修改生产历史账单。

## 交付

- Web 首页和目录统一进入「消费与账单」，消费明细支持服务端搜索及分页，外币账目保留独立分区。手动收支保存后可进入消费工作区。
- Android 将消费明细、账单待处理和最近明细前移；采集订单可从消费直接进入，已入账订单可打开对应消费详情，未入账明确标注仅为材料。
- 付款、购买、餐次与凭证分别展示；两端支持选择已有餐次，经共同 Executor 建立正式关联。Android 明确区分加密队列待同步与服务端结果。
- 账单候选可直接打开已入账或疑似重复的记录；Web 新导入表单折叠，优先查看已有批次。
- 补齐无付款购买的消费列表、只有付款消费的餐次反向关联、付款及直接餐次来源；排除已删除餐次和已作废付款的有效关联，拒绝向失效对象新增关联。
- 修正 Web 同级组件键冲突导致的详情重复渲染，以及无付款购买误编辑首个关联餐次的问题。
- 沿用现有合同和入账规则，没有新增 MCP、自动推断食用、重复生成金额或批量合并历史账目。

[数据含义与入口说明](../architecture/consumption-bill-chain.md)。
