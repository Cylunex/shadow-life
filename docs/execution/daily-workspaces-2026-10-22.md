# 其他生活领域优化交付（2026-10-22）

在 [10 个补充参考项目](../research/daily-workspaces-2026-10-22.md) 的基础上，完善 Web 日常入口与共享查询。没有新增外部运行依赖或数据库迁移。

## 实际交付

| 方向 | 变化 | 数据语义 |
| --- | --- | --- |
| 食品 | 餐单页增加食品期限筛选、独立库存编辑入口；“校正”表单可直接打开，保留原批次备注 | 7 天含今天；余量为零是用完，缺少日期是未知；库存超过 100 批时继续显示覆盖限制 |
| 物品 | 按名称 / 房间 / 柜子搜索已加载物品，筛选退货 7 天、保修 30 天与已过期；修复快速切换物品的二维码响应覆盖 | 非持有物品不进入临期窗口；列表超 100 件有明确提示，定位链接仍可精确读取 |
| 预算 | 计划 → 预算与周期：按月查看预算 / 支出原额，创建及按修订修改预算，创建周期事项，处理 / 跳过 / 恢复期次 | 金额保留十进制字符串；未知金额不写零；期次操作保留关联记录、备注和调整日期，不新增支付或账目 |
| 资料 | 50 条一页连续加载、失败重试、搜索与游标绑定；取消过时列表 / 详情请求；打开资料滚动到正文，关闭回到列表 | 未提交的搜索文本不会改变当前分页条件；旧响应不得覆盖最新选择，轮询也校验当前资料身份 |
| 旅行 | 离线 HTML 包含范围外预订 / 交通、结束 / 到达时间、逐晚住宿和不同清单符号 | 住宿按旅程时区从入住日到退房日前一晚；取消 / 退款不算当晚住宿；其他状态原样标示；未知日期不推断 |

期限算法位于 `packages/kernel/src/planning-attention.ts`。`life.meal_planning` 与 `life.owned_items` 共用 QueryService：

- 输入 `on` 可选；省略时按响应 `as_of` 与 `time_zone` 求日期。时区默认 `Asia/Shanghai`，Web 传入浏览器时区。
- 输出 `stock_attention` / `attention` 标注评估日期、时区、窗口与逐项状态，日历日差不受夏令时小时变化影响。
- 物品查询读 `limit + 1` 后裁剪，返回 `truncated`；注意事项仅覆盖实际返回条目，不把截断列表当成全部。
- HTTP 和 CLI / MCP 的共同 transport 保留两个参数。公开合同、目录快照和 Kotlin DTO 同步生成。
- 新增注意事项字段为可选，缺失时页面显示“未载入”；共享合同仍按整个版本发布，本轮没有发布动作。
