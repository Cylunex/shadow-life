# 训练自选菜单交付记录 · 2026-10-16

## 已实现

- 一个版本化动作菜单保存部位优先级、每周主题及备选动作，默认居家模板 40 项，包含徒手／哑铃及三档难度。
- Web 健康页和 Android 健康的训练标签支持筛选、今天的组合、独立调整今天主题、保存新菜单或版本检查更新既有计划。
- 默认主题为周一胸、周二腰腹、周四胸，可搭配核心、背肩与少量手臂／腿部；这只是模板，没有自动写入任何个人账号。
- 实际训练保存动作快照和逐组次数／秒数、选填的每只哑铃公斤数。未填写的动作跳过，不补造时长、热量、重量和主观强度。
- 复用既有 health 能力、Executor、权限、事务、幂等和账号加密同步队列；不新增数据库迁移。
- 健康计划分页读取返回 schedule/detail，旧版自由 JSON 信息保留，菜单与实际执行的保留字段由共享合同统一校验。
- 力量训练不再按时长给出自动加量建议。文字提示、动作分类与动作库引用集中维护，Android 资源由 contracts 生成并检查一致性。

## 验证

- `pnpm check`：合同生成、依赖边界、TypeScript 类型与各工作区常规测试通过。
- `pnpm test:full:offline`：隔离本地 PostgreSQL，369/369 通过（无跳过），涵盖菜单持久化／读取、计划版本冲突、权限、执行幂等和计划不产生事实。
- `pnpm --filter @shadow/web build`：通过；保留既有大型 bundle 提示。
- `pnpm test:workout:offline`：真实本地 API + 隔离数据库 + Chrome，桌面 1440px 与手机 390px 下筛选、保存、只记录实际填写组数、主题不随浏览筛选改变、重载菜单和无横向溢出通过。
- Android JDK 17：`:app:compileDebugKotlin :app:testDebugUnitTest` 和全模块 `testDebugUnitTest` 通过，50 个单元测试结果无失败；不是实机验收。
- 本地浏览器截图确认卡片文字、深色模式对比、部位选择与手机宽度下的输入布局。

## 交付边界

只修改项目代码和通用文档，没有部署、构建 APK、写入线上个人计划、设置 Hermes 提醒或更改 NAS 资料。
内置文字库在 Android 可离线浏览；已保存菜单目前仍通过在线计划接口读取。
教学参考主要链接到公共动作库，**本次未新增 40 个动作的逐动作离线示范图／视频**，不能将文字离线库当作已完成离线媒体交付。
当前仍是训练菜单讨论稿，下一次可在讨论结论基础上再保存个人计划、补齐对应离线演示素材。
