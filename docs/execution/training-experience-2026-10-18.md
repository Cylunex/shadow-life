# 首页训练入口与训练流程 · 2026-10-18

## 结果

训练不再需要先进入健康趋势寻找。Android 首页新增首位训练卡片，显示可读取的当天安排／自由练状态；已自定义首页只做一次新卡片引入，随后保留用户隐藏和排序。独立训练页面保留返回入口，计划页和原健康训练入口共用同一个训练组件。Web 首页增加同样入口和独立训练分区。

训练组件按今日训练、动作库、我的计划区分操作，搜索可跨部位找飞鸟。今日组合支持排序，开始后显示每组次数／秒数、可选每只哑铃重量，以及完成和撤销。组间休息使用绝对结束时刻，后台恢复仍显示实际剩余时间，可调整或跳过。输入值没有点击完成时仍是草稿。

## 数据边界

继续使用 `health.records`、`health.set_plan` 和 `health.record_workout`，合同、数据库和 Executor 不变。只把确认完成的组送入既有力量记录合同，不根据选择动作制造事实，也不补造重量、热量或时长。修改菜单保留既有每周日期安排、其他备注与修订版本。

Android 草稿加密并按账号保存，包含原始记录日、时区、动作快照、逐组状态与休息期限。提交前冻结输入和稳定命令 ID，重复加入既有账号队列使用同一命令。Web 草稿按服务端身份隔离，使用当前标签页会话存储，校验动作快照、单位、重复动作、数量与已完成数值后恢复。Web 写入继续使用已有 CommandController 的幂等与回执恢复。

- `pnpm test:full:offline`：一次性本机 PostgreSQL 完整回归 373/373，无跳过。
- Web 生产构建通过。
- `pnpm test:workout:offline`：真实本机 API、一次性 PostgreSQL 与 Chrome 覆盖首页入口、筛选搜索、选择不产生事实、保存计划、逐组完成／撤销、只保存确认组、每组重量、草稿恢复、休息到期、保存后不重放；1440px 和 390px 检查无横向溢出及页面异常。
- Android `:app:compileDebugKotlin testDebugUnitTest`：编译与全部 64 个单测通过，新增训练草稿、单位与重量、恢复命令、计时和首页卡片引入用例。

## 限制

本次验证为本机浏览器流程和 Android 编译／JVM 单测，没有连接生产、修改个人训练安排、创建 Hermes 提醒、构建签名 APK 或在真机安装；Android 触摸布局与后台系统行为尚需设备验收。动作示范仍使用现有教学链接与独立离线资料，未新增内置视频或下载器。Web 长期草稿不跨标签页关闭保留，Android 已保存计划不新增离线缓存。
