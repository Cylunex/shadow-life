# Life 模块导航与生活首页

## 实现范围

本轮实现 Android 原生客户端。生活首页按固定顺序显示：

1. **常用**：消费、健康、饮食、训练、出行、物品、资料及服务中心。
2. **最近记录／消息**：记录与消息在同一区域切换，默认最多显示两条；记录可展开或进入全部记录，消息进入已有提醒收件箱。采集中的本机状态、已入账记录、读取失败分别沿用实际数据。
3. **我的卡片**：保留原有称重接收、健康趋势、饮食、消费、训练、行程等卡片，以及拖动排序、置顶、隐藏和紧凑显示。

最近信息从可排序卡片中移至固定区域；升级只移除旧布局中的 `recent_info`，不改变其余卡片顺序，不恢复用户隐藏的卡片。新账号默认保留体脂秤和身体分析入口。首页名称始终为“生活”。

## 模块与服务中心

- 顶部当前模块名称打开模块面板；共七个入口：生活、健康、饮食、消费、出行、物品、资料。顶部同时提供服务中心、快速记录，以及助手、提醒、设置和其他项目菜单。
- 生活底部为概览、日程、记录。健康为概览、身体、睡眠、运动；饮食为今天、餐单、食材、采购；消费为概览、明细、统计、预算；出行为旅程、行程、地图、地点。
- 物品和资料保留各自已有的搜索与分类，不人为补充空栏目。
- 服务中心复用原功能目录与记录搜索，无关键词时按领域展示双列功能入口，搜索时显示完整任务说明与真实记录结果。消费统计、预算可直接进入指定栏目。
- 次卡、账单待处理、订阅、想买、消耗品保留在消费概览；训练、起飞记录、食谱等继续可达。
- 消费统计使用已有统计口径，明确标记已加载明细，按原币种分开；不把分页明细包装成完整月度总额。

## 返回与状态

各领域使用不同的 Navigation 根目的地，避免参数不同但路由类型相同导致恢复到错误模块。普通模块切换恢复已保存的返回栈、栏目、搜索输入及各栏目滚动位置；服务中心直达指定栏目时，回到对应模块根页并采用本次请求，重复点击同一入口也生效。

模块已读取的记录页在当前账号会话内保留，切回后沿用已有刷新提示，不清掉已翻页内容。切换账号或退出时清空这些快照；不同领域读取使用现有异步代次保护。实际记录查询、写入、加密队列及 Executor 成功口径保持原边界。

## 验证与限制

- JDK 17、Android 36：应用 Kotlin 编译通过，111 项应用单元测试全部通过；debug lint 无错误，报告 61 项警告及 1 项提示。
- 新增 Compose / Robolectric 导航回归：跨模块栏目／搜索／滚动恢复，重复指定栏目，恢复详情后的直达入口，320dp 模块菜单与服务入口，以及旧卡片布局迁移和账号隔离。
- 模块依赖边界检查与 Git 差异检查通过。

Compose 测试使用合成内容与 Android 34 模拟运行环境；它验证真实导航与公共界面组件，不代表已安装 APK 的真机验收。未修改 Web、部署服务、构建 APK 或安装手机。
