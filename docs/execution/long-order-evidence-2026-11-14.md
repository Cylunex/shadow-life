# 长订单识别与价格核对

长订单中的商品实付与整单实付使用相同字段名，原来的逐行解析会把它们当成冲突。图片候选现在按商品、费用、合计、订单信息和推广区域解析，保留真正的整单金额冲突。旧的平铺付款材料仍可读取。

图片付款观察新增可选的订单号、下单时间及 `price_check`。核对以整数分计算，分别比较总价减总优惠与实付、可见优惠项之和与总优惠。重复观察不会重复扣减；证据不足返回 null，不假定缺失项为零。下单时刻不替代支付时刻，查询不产生入账或回填。

回归覆盖分段缺项、商品价与整单价、同一字段真正冲突、优惠差异、重叠重复、Markdown 和旧平铺格式；数据库端验证原件与识图任务溯源及只读行为。公开契约生成物与客户端共同更新。真实发布和模型验收在工作区运维回执中记录。

验证：`pnpm check`、完整隔离数据库回归 562/562、Android 应用 151 项及 data 3 项单测通过。
