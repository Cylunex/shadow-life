# 保存网页快照与找回助手运行

## 网页资料

在浏览器中用 SingleFile 保存网页，或准备 UTF-8 HTML 文件。打开 Life Web → 资料 → 录入资料，选择文件，
按需填写标题和原网址，然后上传。Life 先保存固定原件，再在后台提取正文，处理状态会自动刷新。
不需要选择处理器，也不需要原网站仍能访问。

正文完成后，可以在资料中阅读、用中文完整词或英文词搜索，并展开“原件提取片段与来源”。
“下载原件”保存原始 HTML；页面中的阅读内容是纯文本。原网址只允许 HTTP/HTTPS，收藏同一个网址或
同一个文件的新操作会建立新资料副本。

出现编码、大小、结构或时间限制时，原件仍然保留。可以下载原件、重新导出 UTF-8 文件另存，或对失败任务
点击重试。重试不会替换固定原件。登录、订阅或截断说明表示提取内容可能不完整，需要核对原件。
普通的复杂排版也可能影响提取；可以直接更正资料正文，更正会保存历史修订。

上传或保存途中断网时，重新打开录入区并选择“从当前阶段继续”。该操作会核对并继续原命令，
不会因为再次点击而重复建立资料。需要另存新副本时，应等原流程完成后重新选择文件上传。

## 助手运行

助手显示由实际调用产生的活动卡片。模型回复中的“已保存”文字本身不构成保存回执；
实际保存会另有可信活动和执行回执。

连接中断后会显示“正在恢复结果”，上线后继续读取原运行的进度、来源和结果。
刷新页面后重新打开生活助手，会找到原线程最近的运行并重建视图。恢复期间不必重新发送同一条消息。
浏览器后台时检查频率会降低，重新上线会唤醒恢复等待。

点击停止后先显示“正在停止”。如果停止请求没有确认，会继续观察原运行；可以再次点击停止。
停止成功后，之前已保存的内容和回执仍然保留，停止不会撤销已经提交的记录。
运行因服务进程退出而中断时，会显示实际中断状态；界面恢复不会自动续跑模型或补执行写入。

当前交付覆盖 Web；Android 继续使用已有页面和共享后端。网页自动抓取、PDF 页级解析、同条资料的多次
快照历史、离线正文缓存和语义检索不属于本批功能。
